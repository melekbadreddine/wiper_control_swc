# Glossary

* **SWC / SW-C** — Software Component (AUTOSAR Software Component).
* **RTE** — Runtime Environment; AUTOSAR abstraction layer between SWCs and BSW.
* **BSW** — Basic Software (OS, COM stack, drivers, Diagnostics).
* **MCAP** — recording container for telemetry/robotics data (used for replay).
* **DBC** — CAN database description (signal mapping).
* **ARXML** — AUTOSAR XML model files (AUTOSAR 4.x schema here).
* **Runnable** — AUTOSAR notion of a schedulable function (init/cyclic/data-received).
* **MIL/SIL/PIL** — model/software/processor in the loop testing levels.
* **HARA** — Hazard Analysis and Risk Assessment (ISO 26262‑3).
* **ASIL** — Automotive Safety Integrity Level (QM/A/B/C/D).
* **DTC** — Diagnostic Trouble Code.
* **IoHwAb** — I/O Hardware Abstraction (AUTOSAR ECUs layer).
* **Dem/Det** — Diagnostic Event Manager / Development Error Tracer.
