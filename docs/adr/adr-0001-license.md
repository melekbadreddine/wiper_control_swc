# ADR-0001 — MIT license

* Status: **Accepted** (milestone M0)
* Date: 2026-11-03

## Context
Published artifacts need a license for the repository, generated code, docs.

## Decision
MIT license for all code.

## Reason
Permissive, single short text, ecosystem standard; the project is an academic
artifact. No OEM confidentiality constraints exist in this exercise.

## Consequences
Re-evaluate if a supervisor requires e.g. Apache-2.0 (IDENTICAL OPTION).
